# Sunrise Cafe & Bakery

**Live Project:** [Sunrise Cafe & Bakery](https://sunrise-cafe-aus.netlify.app/)  
**Repository:** [sunrise-cafe-files](https://github.com/areye2020/sunrise-cafe-files)

> A modern, responsive website built for a fictional brunch cafe and bakery in Austin, TX. This project demonstrates end-to-end frontend development, from initial project planning to deployment, emphasizing web performance, accessibility, and modern software engineering practices.

---

## Project Overview

The Sunrise Cafe & Bakery website was developed to provide a warm, user-friendly digital storefront. The site features dynamic menu filtering, responsive photo galleries, and serverless form handling. Behind the scenes, the project was managed using professional development workflows, including Agile task tracking, feature branching, and performance auditing.

---

## Technical Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Integrations:** Formspree (Newsletter), Google Maps Embed
* **Version Control:** Git & GitHub (Feature Branches, Pull Requests)
* **Deployment:** Netlify
* **Tools:** VS Code, Lighthouse, TinyPNG

---

## Development Lifecycle & Skills Demonstrated

### 1. Project Planning & Version Control
Structured the development process using a Kanban board via GitHub Projects to track to-do items and manage project scope. Maintained a clean version control history by utilizing feature branches and submitting Pull Requests before merging updates into the main repository.

### 2. Frontend Development & Customization
Engineered a responsive layout tailored for multiple viewports (tested across 375px, 768px, and 1440px). 
* **Dynamic Filtering:** Implemented JavaScript logic to allow users to seamlessly sort menu items by categories (All, Brunch, Bakery, Drinks).
* **Asset Management:** Replaced initial wireframe placeholders with optimized, high-quality images mapping to specific site sections (Hero, Interior, Gallery).
* **Integrations:** Linked the "Order Online" functionality to a Square POS placeholder, embedded an interactive Google Map for the 2847 S Lamar Blvd location, and configured Formspree to capture newsletter subscriptions without a dedicated backend.

### 3. Quality Assurance & Performance Tuning
Conducted cross-browser and multi-device testing to ensure cross-platform compatibility. 
* **Lighthouse Auditing:** Ran audits focusing on speed, accessibility, and web performance.
* **Optimization:** Identified large asset bottlenecks and compressed images to under 500KB. This direct intervention boosted the site's Lighthouse scores to **98 for Performance** and **92 for Accessibility**.

### 4. SEO Optimization & Deployment
Configured essential metadata to improve search visibility and social media sharing previews.
* **SEO & Open Graph:** Added precise `<title>` tags, meta descriptions, and `og:image` / `og:title` tags for link previews across social platforms.
* **Continuous Deployment:** Successfully deployed the production-ready build to Netlify, ensuring all relative paths, compressed assets, and form submissions functioned correctly in the live environment.
